## Infinite ground

The horizontal placement boundary is removed. Existing save origins remain unchanged through `gridOriginOffset`; only the 96-plate height limit remains. Occupancy uses nested numeric maps, so negative and distant coordinates cannot alias across the former 32-stud boundary. Picking clips DDA traversal to occupied bounds before visiting exact cells.

`npm run test:world` checks actual placement beyond both former edges, a camera/build 1,024 studs away, distant L masks, picking/delete, undo/redo and autosave/reload. Additional logic tests exercise separated cells out to ±1,000,000 and mirrored L notches at negative origins. Ground resources stay fixed: two render meshes and a reusable pool of 9,216 nearby stud instances, with a repeating procedural far surface. Axis guides and lighting follow the working area. The camera can dolly farther for larger builds. Its damped quaternion is normalized after interpolation so tiny rounding errors cannot keep idle frames running; a variable-timestep camera test covers this case.

Evidence: [world checks](test-results/infinite-world.json), [initial view](test-results/infinite-world.png), [distant view](test-results/infinite-world-distant.png). The older finite-world screenshots and benchmark entries below describe the preceding catalog revision. The core browser suite now checks unsupported red targets instead of horizontal out-of-bounds targets.

## Persistence and performance

All localStorage access now passes through `src/storage.ts`, which catches unavailable storage and malformed JSON. Palette/settings decoders validate their version, shape, limits and values. Browser tests confirmed in-memory operation and JSON export with localStorage blocked. A pre-revision v1 two-brick build retained its exact IDs, literal colors and cells while corrupt preferences fell back safely. Build version remains 1; optional mirror defaults to false. Known malformed pieces remain errors; unknown types are warned/skipped with a toast.

The mixed 2,000-piece scene uses 24 types, 26 type/mirror variants, and 30 draw calls; the renderer frame counter stopped advancing while idle. Geometry/material sharing, instance capacity growth, pixel-ratio cap, snapping and placement animation remain in place. Software tests reduce pixel ratio during stress rendering; these are functional and CPU-clear measurements, not laptop/phone FPS claims.
