## Persistence and performance

All localStorage access now passes through `src/storage.ts`, which catches unavailable storage and malformed JSON. Palette/settings decoders validate their version, shape, limits and values. Browser tests confirmed in-memory operation and JSON export with localStorage blocked. A pre-revision v1 two-brick build retained its exact IDs, literal colors and cells while corrupt preferences fell back safely. Build schema/version stays unchanged because it already used literal hex values.

The 2,000-brick regression scene used 5 draw calls; the renderer frame counter stopped advancing while idle. Geometry/material sharing, instance capacity growth, pixel-ratio cap, snapping and placement animation remain in place. Software tests reduce pixel ratio during stress rendering; these are functional and CPU-clear measurements, not laptop/phone FPS claims.
